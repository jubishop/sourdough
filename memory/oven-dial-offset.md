# Oven dial offset

The user's oven runs 15°F cooler than its dial. Every oven temperature in
the recipe is the dial setting, not the actual oven temperature. For
example, a 415°F setting in the recipe means about 400°F in the oven.

The user reported this offset on 2026-10-13. It supersedes the 25°F offset
recorded on 2026-09-17 in the recipe guide's
[oven temperature adjustment](../docs/recipe-guide.md#oven-temperature-adjustment).
The user did not say how it was measured.

When the user gives a recipe temperature, treat it as a dial setting unless
they say otherwise. Subtract 15°F to compare a setting with an actual
temperature, such as in an outside recipe or bake research.
